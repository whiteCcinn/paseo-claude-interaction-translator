# 对抗式审查 01

范围：本项目初版的翻译后端、输入状态机、轮次状态机、Paseo 入口和 React 展示。

## 规格审查

结论：下表问题均有复现和回归测试，修复后独立复审通过。复审分别运行后端 21 项和集成/状态/UI 28 项测试，全部通过；两份 TypeScript 检查通过。

| 编号 | 发现的问题 | 修复与证据 |
| --- | --- | --- |
| R01-001 | CLI 包装器的后代持有管道，取消后请求与并发槽位无法结束 | 独立进程组清理、关闭自有管道并及时 settle；真实双进程树测试通过 |
| R01-002 | 中文目录路径仅保护了 ASCII 片段 | Unicode、引号空格与 UNC 路径整段保护测试通过 |
| R01-003 | Markdown 缩进代码交给模型翻译 | 四空格与 Tab 缩进代码保护测试通过 |
| R01-004 | 占位符与 JSON 转义可使请求体超过上限 | 发送前检查序列化后的 512 KiB 上限，验证超限时无 HTTP 请求 |
| R01-005 | 发送过程中更改设置，revision 变化使发送状态永久锁死 | 已确认发送始终释放锁；设置变更回归测试通过 |
| R01-006 | 关闭会话后，等待设置的重试可重新启动 | 跨 await 校验轮次所有者、取消状态与卸载状态；关闭中重试回归通过 |
| R01-007 | 停用插件时挂起的旧设置读取可使用新生命周期发送翻译 | 请求开始时捕获生命周期，读取和翻译后再次校验；延迟读取回归通过 |
| R01-008 | 切换语言/后端后旧 Query 缓存仍显示旧配置译文 | 缓存键包含设置 revision；实际 React 渲染旧 TanStack 缓存回归通过 |

还修复并保留了 64K 长普通 token、长占位符前缀的性能回归测试，避免沿用旧保护正则时出现秒级耗时或正则过大错误。

## 代码质量审查

独立 TypeScript 审查补充发现两项资源边界问题，均已建立失败用例并修复：

| 编号 | 发现的问题 | 修复与证据 |
| --- | --- | --- |
| R01-009 | CLI 正常或非零退出后，同进程组中关闭管道的辅助进程仍存活 | POSIX close 时回收本次独立进程组；退出码 0/2 的真实 helper 回归均通过；Windows 不使用已退出父进程的旧 PID |
| R01-010 | 隔离验证脚本在 stop 失败或 stop 自身挂起、忽略 SIGTERM 时无法退出 | 管理命令也使用独立进程组和有限超时；限时等待后只升级终止自己的进程组，确认退出后清理 home；两项实际假 daemon 回归先失败后通过 |

结论：修复后独立 TypeScript 复审通过，无剩余已证实的 P1/P2。审查者独立运行 53/53 项测试、两份 TypeScript 检查及 `git diff --check`，均通过。

Windows 正常退出后的孤儿进程无法由 Node 核心 API 可靠追踪，已在实现和验证边界中注明；当前实际验证平台为 macOS。
